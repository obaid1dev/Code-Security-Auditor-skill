From signal to secure fix

More than a list of scary warnings.

Every finding is grounded in your code, prioritized by impact, and paired with a practical next step.

Find what matters

Surface secrets, injection, auth and access-control gaps, unsafe configuration, and more. Candidates are read and triaged—not blindly copied into a report.

Fix, without the churn

Get minimal, stack-idiomatic patches. Behavior-changing fixes are proposed for your approval; existing tests and checks are used to verify changes where possible.

Leave with a clear report

Generate a before-and-after SECURITY_AUDIT.md with severity, CWE, exact locations, fixes, and follow-up actions. Optional SARIF is ready for code scanning.

A careful workflow

Know what changed—and why.

Use the AI skill for a guided, context-aware audit, or run the standalone Python scanner as a quick first pass.

Map your attack surface

Review routes, inputs, configuration, CI, containers, and relevant security rules.

Detect and verify

Connect candidates to real source code and score severity, confidence, and impact.

Patch and re-check

Make the smallest safe change, then re-scan and run available project checks.

Deliver an actionable report

Separate fixes, decisions, and anything that still needs human verification.

Standalone scanner · Python 3.9+no dependencies
# Find candidates in a project
python code-security-auditor/scripts/scan.py ./my-project --out findings.json

# Generate a Markdown report and optional SARIF
python code-security-auditor/scripts/report.py findings.json \
  --out SECURITY_AUDIT.md --sarif audit.sarif
